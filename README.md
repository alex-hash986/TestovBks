# Сервис уведомлений об оплате по расписанию

Скрипт на чистом Python для автоматического мониторинга базы клиентов из Excel-файла и отправки персонализированных напоминаний о необходимости оплаты через Telegram Bot API.

Реализовано строго без использования no-code платформ (n8n, Make и аналоги).

---

## 📌 Функционал

1. **Чтение данных из Excel:** считывает контакты и данные по платежам (`Имя`, `Номер телефона`, `Сумма`, `Дата`).
2. **Фильтрация по дате:** находит записи, срок оплаты которых наступает сегодня.
3. **Шаблонизация сообщений:** генерирует персонализированный текст с указанием суммы и дедлайна.
4. **Отправка через Telegram Bot API:** прямые HTTP-запросы без тяжёлых фреймворков.
5. **Планировщик (Scheduler):** работает в фоновом режиме демона с ежедневным запуском по заданному расписанию (по умолчанию в 10:00).

---

## 🛠 Стек технологий

* **Python 3.10+**
* **pandas** / **openpyxl** — чтение и обработка таблиц Excel.
* **requests** — интеграция с Telegram Bot API.
* **schedule** — планировщик задач.
* **python-dotenv** — безопасная работа с переменными окружения.

## 🚀 Установка и запуск
1. Клонирование и подготовка окружения

# Создание виртуального окружения (рекомендуется)
python -m venv venv

# Активация окружения:
# Для Windows:
venv\Scripts\activate
# Для Linux / macOS:
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

2. Настройка конфигурации

    Скопируйте файл .env.example в .env:
    
    cp .env.example .env

    Укажите ваши реальные параметры в .env:

        BOT_TOKEN — токен бота от @BotFather.

        TELEGRAM_CHAT_ID — ID чата для получения уведомлений.

        EXCEL_PATH — путь к Excel-файлу (по умолчанию clients.xlsx).

3. Запуск сервиса

python main.py

При запуске скрипт сразу выполнит первую тестовую проверку базы, после чего перейдёт в режим ожидания ежедневного времени (10:00).
⚙️ Развёртывание на сервере (Linux / VPS)

Для постоянной работы в фоновом режиме на сервере можно использовать systemd или nohup:

nohup python3 main.py > bot.log 2>&1 &
